## 2. 目标与范围

**目标**
- 电影感内容生成入口，提升首屏转化与沉浸体验。

**范围**
- 首页：视频背景 + 搜索入口 + 电影胶片
- 登录：全局弹窗
- 灵感广场：瀑布流 + 返回主页

**不做**
- 后端内容生成
- 第三方登录

## 3. 关键流程

1. 访问首页
2. 点击输入框聚焦 → 遮罩/玻璃态
3. 未登录触发登录弹窗
4. 进入灵感广场浏览

## 5. 交互说明（要点）

- 点击头像打开菜单，点击外部或 5 秒无操作关闭。
- 输入框聚焦：高度变大、背景模糊、遮罩覆盖。
- 发送按钮：有文字显示白底黑箭头，无文字为默认样式。
