# PRD（轻量版）

## 1. 目标
- 提供电影感的内容生成入口，快速输入灵感并生成视频相关内容。
- 通过沉浸式视觉（视频背景、电影胶片、玻璃质感）提升品牌氛围。

## 2. 范围
- 首页：视频背景 + 搜索/输入入口 + 电影胶片展示
- 登录：账号密码登录弹窗（全局可用）
- 灵感广场：瀑布流内容区 + 返回主页 + 顶部头像/登录
- 侧边栏：主页/灵感广场入口 + 图标状态

## 3. 关键流程
1) 访问首页
2) 点击输入框聚焦 → 玻璃遮罩 → 输入灵感
3) 未登录时触发登录
4) 进入灵感广场浏览灵感内容

## 4. 关键功能（概述）
- 全局登录弹窗与登录态
- 首页输入框聚焦态与发送/附件交互
- 电影胶片展示与自适应
- 灵感广场瀑布流与返回入口
