# 工作流页面滚动问题记录

## 问题现象
- 访问：`/workflows/pro/step-1`
- 页面右侧出现外层白色滚动条（浏览器整体滚动）。
- 期望：仅页面内部内容区域滚动，不出现外层滚动条。

## 影响范围
- 工作流相关页面：
  - `/workflows`
  - `/workflows/beginner`
  - `/workflows/pro/step-1` ~ `/workflows/pro/step-5`

## 当前处理方案
1. **锁定全局滚动**
   - 在 `WorkflowShell` 挂载时给 `html` / `body` 添加 `workflow-scroll-lock` 类。
   - 类中设置 `overflow: hidden`，防止外层滚动。

2. **内部容器滚动**
   - 工作流页面 `main` 使用 `h-screen overflow-hidden`。
   - 内部内容容器使用 `overflow-y-auto`，并加 `no-scrollbar`。

## 可能原因
- 内部元素高度溢出触发浏览器滚动。
- macOS 系统设置为“始终显示滚动条”，导致看起来外层有滚动条。
- `min-h-screen` / `h-screen` 在嵌套布局中叠加导致溢出。

## 后续排查方向
- 检查是否还有未移除的 `min-h-screen` 造成溢出。
- 在浏览器中确认滚动条归属元素（html/body vs 内部容器）。
- 如系统滚动条始终显示，可考虑在内容区添加右侧内边距做视觉规避。
