# 前端知识点速记

## 事件冒泡与 stopPropagation

**概念**
- 事件冒泡（bubbling）：事件从子元素触发后，会向父元素一直传播，直到 `document`。
- `stopPropagation()`：阻止事件继续向上冒泡，只在当前元素处理。

**常见场景：点击外部关闭弹窗/菜单**
- 典型做法：在 `document` 上监听点击，关闭弹窗。
- 问题：点击弹窗内部的按钮也会冒泡到 `document`，被当作“外部点击”而关闭。
- 解决：在弹窗容器上阻止冒泡，例如：

```tsx
<div onMouseDown={(e) => e.stopPropagation()}>
  {/* 弹窗内容 */}
</div>
```

**补充**
- 使用 `onMouseDown` 而非 `onClick` 可以更早阻断事件，避免某些情况下先触发外部关闭。
- 也可以在外部关闭逻辑里判断 `event.target` 是否位于弹窗内部。
