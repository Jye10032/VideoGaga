# 工作流页面接口需求（逻辑版）

## /workflows（模式选择）

- 获取默认配置
  - 触发时机：页面加载
  - 需要字段：默认画面比例、默认创作模式、默认分镜图模式、默认风格（若有）
- 创建新项目
  - 触发时机：点击“创建新项目”
  - 需要字段：项目名、选择的模式（小白/专业）、可选初始参数
  - 返回字段：项目 ID、项目名、当前步骤（用于跳转）

## /workflows/pro/step-1（故事设定）

- 获取故事设定草稿/最终稿
  - 触发时机：页面加载
  - 需要字段：项目 ID
  - 返回字段：故事内容、是否已确认、最近更新时间
- AI 生成故事（对话流）
  - 触发时机：点击“发送”
  - 需要字段：项目 ID、用户输入、历史上下文（先不做）
  - 返回字段：AI 回复文本
- 保存故事设定（确认）
  - 触发时机：点击“提交”
  - 需要字段：项目 ID、故事内容
  - 返回字段：确认状态、更新时间
- 重新编辑故事设定
  - 触发时机：点击“重新编辑”
  - 需要字段：项目 ID
  - 返回字段：故事内容（可编辑态）

## /workflows/pro/step-2（参数设定）

- 获取项目参数
  - 触发时机：页面加载
  - 需要字段：项目 ID
  - 返回字段：画面比例、创作模式、分镜图生成模式、画面风格
- 保存/更新参数
  - 触发时机：用户选择后点击“下一步”
  - 需要字段：项目 ID、参数值
  - 返回字段：保存结果

## /workflows/pro/step-3（场景 / 角色 / 道具）

- 获取素材列表
  - 触发时机：页面加载
  - 需要字段：项目 ID
  - 返回字段：场景/角色/道具列表（含名称、描述、图片、状态）
- 新增/编辑/删除素材
  - 触发时机：点击新增、编辑名称、删除
  - 需要字段：项目 ID、素材类型、素材 ID、名称/描述
  - 返回字段：更新后的列表或单条数据
- 上传素材图片
  - 触发时机：点击“本地上传”
  - 需要字段：项目 ID、素材类型、素材 ID、图片文件
  - 返回字段：图片 URL、上传状态
- AI 生成素材图片
  - 触发时机：点击“AI 自动生成”或“一键生成”
  - 需要字段：项目 ID、素材类型、素材 ID、描述/提示词
  - 返回字段：生成状态、图片 URL 列表
- 保存素材描述/提示词
  - 触发时机：点击“场景描述/提示词”提交
  - 需要字段：项目 ID、素材 ID、描述/提示词
  - 返回字段：保存状态

## /workflows/pro/step-4（分镜脚本）

- AI 生成分镜列表
  - 触发时机：点击“AI 一键生成分镜”
  - 需要字段：项目 ID、故事设定、素材列表、参数设定
  - 返回字段：分镜列表（含场景、角色、道具、画面描述、台词、说话人、时长）
- 获取分镜列表
  - 触发时机：页面加载
  - 需要字段：项目 ID
  - 返回字段：分镜列表
- 新增/删除分镜
  - 触发时机：点击“添加分镜”/删除按钮
  - 需要字段：项目 ID、分镜 ID
  - 返回字段：更新后的列表
- 更新分镜内容
  - 触发时机：点击“编辑”并保存
  - 需要字段：项目 ID、分镜 ID、更新字段
  - 返回字段：保存状态
- 上传/选择分镜图
  - 触发时机：点击“从场景选择/从本地上传”
  - 需要字段：项目 ID、分镜 ID、图片/素材引用
  - 返回字段：分镜图 URL
- 分镜排序
  - 触发时机：拖拽调整顺序
  - 需要字段：项目 ID、分镜顺序数组
  - 返回字段：保存状态

  - 需要字段：项目 ID、台词、说话人/音色
  - 返回字段：任务 ID、任务状态
- 查询生成状态
  - 触发时机：页面轮询/用户刷新
  - 需要字段：项目 ID、任务 ID
  - 返回字段：进度、结果音频 URL

## /workflows/pro/step-7（视频预览）

- 获取预览视频
  - 触发时机：页面加载
  - 需要字段：项目 ID
  - 返回字段：合成视频 URL/封面图
- 查询合成状态
  - 触发时机：页面轮询/用户刷新
  - 需要字段：项目 ID
  - 返回字段：状态（生成中/完成/失败）、错误信息（如有）
