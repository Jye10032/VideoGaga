# 模式选择

## 基本信息

| 字段 | 内容 |
| --- | --- |
| 页面 | 模式选择 |
| 路由 | `/workflows` |
| 涉及表 | `projects` |
| 更新日期 | 2026-02-08 |

## 功能说明

用户从"我的项目"页面或首页创建项目后进入此页面，选择创作模式：

- **小白模式（Beginner）**：一句话输入，AI 全自动生成。（暂未实现）
- **专业模式（Pro）**：7 步全流程可控。

选择后跳转到对应模式的第一步。

## 需要的接口

### 1. 创建项目

用户在首页输入项目名称并回车时，创建项目并获取 `id`，然后跳转工作流。

**前端触发时机**：首页 HeroPrompt 输入框回车。

```
POST /api/v1/projects
```

**Request：**

```json
{
  "name": "我的动画短片",
  "description": ""
}
```

**Response（对应 `projects` 表）：**

```json
{
  "id": "uuid",
  "user_id": "uuid",
  "name": "我的动画短片",
  "description": "",
  "aspect_ratio": "16:9",
  "creation_mode": "image_to_video",
  "storyboard_mode": "single",
  "style_id": null,
  "current_step": 1,
  "version": 1,
  "created_at": "2026-02-08T10:00:00Z",
  "updated_at": "2026-02-08T10:00:00Z"
}
```

**前端拿到 `id` 后跳转**：`/workflows?id=<project_id>`

### 2. 获取项目详情

**前端触发时机**：模式选择页加载时，根据 URL 中的 `id` 获取项目信息。

```
GET /api/v1/projects/:id
```

**Response**：同上述 `projects` 表结构。
