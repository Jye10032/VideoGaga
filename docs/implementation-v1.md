## 实施边界

新增工作台使用原框架与现有项目表，以独立版本化文档表保存资产/分镜，避免对线上旧表进行破坏性变更。旧工作流入口导向完整工作台。演示项目和图片保存在浏览器 IndexedDB（避免媒体占满 localStorage）；账号项目通过鉴权 API 保存，禁止网络失败时偷偷退回演示数据。

## 本地启动

无需账号/API Key：进入 `frontend`，执行 `npm ci`、`npm run dev`，打开 `http://localhost:3000/projects`，选择“开始本地演示”。示例故事可走完整六步并导出视频。

账号项目：进入 `backend`，创建 Python 虚拟环境并安装 `requirements.txt`，将 `.env.example` 复制为自己的 `.env`。填写自行生成的 `JWT_SECRET`（至少 32 字符），初次安装可设置随机的 `BOOTSTRAP_ADMIN_INVITE`（16–32 字符、仅允许一次注册）。执行 `.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000`。首次管理员注册后，在 `/admin` 创建其他邀请码、停用邀请码或启停用户。SQLite 仅用于本地单进程体验；正式多实例使用 PostgreSQL 并保持证书校验。

前端可用 `NEXT_PUBLIC_API_BASE_URL` 指定后端；默认开发地址为 `http://localhost:8000`。模型 API 的基础地址、Key、模型 ID 在 `/settings` 按用途分别填写。保存不会发出测试请求。配置按登录账号隔离，仅保存在 localStorage，退出账号即清除该账号配置；演示媒体及失败恢复草稿使用 IndexedDB。服务端仅在当前调用内使用传入的配置，不保存 Key、基础地址或模型配置正文。

## 接口边界

- 文本：`POST {baseUrl}/chat/completions`，返回 `choices[0].message.content`。剧本拆解要求返回指定 JSON，格式错误会显示失败。
- 图片：`POST {baseUrl}/images/generations`，返回 `data[0].url` 或 `b64_json`。图像尺寸为 1536×1024、1024×1536 或 1024×1024，最终导出按项目比例裁切。
- 配音：`POST {baseUrl}/audio/speech`，返回音频；当前使用 MP3 格式。
- 视频：自定义 JSON 任务协议，提交 `/videos`，字段为 `model/prompt/duration/aspect_ratio`；返回任务 `id`，查询 `/videos/{id}`，完成后提供 `url` 或 `video_url`。这是文字到视频适配，**尚未向供应商传入角色参考图或分镜首帧**，不代表兼容所有厂商原生接口，也不代表已解决视觉一致性。
- 外部请求限公开 HTTPS 443，DNS 解析后固定 IP，验证 TLS，不跟随重定向。访问内网、保留地址会拒绝；媒体代理仅接受图片、视频、音频，拒绝 SVG。
- 请求使用持久化任务 ID。超时、连接中断或无法确认执行结果时保留“待确认”，查询原任务后才可明确重交；后端锁定项目并检查同输入的未决任务。任务状态不会因刷新而伪装成功。
- 保存有版本比较；冲突不会覆盖另一个窗口的版本。未保存草稿按账号与项目保存在本机，重新打开时提供恢复及放弃入口；成功清理草稿时须与所保存的快照一致。

新增 StudioDocument、StudioRun、OAuthIdentity 表，不删除已有业务表。旧项目首次打开时继承原始剧本，旧场景/任务记录保留在原表，当前未自动迁移成新版分镜。旧的未鉴权生成入口已停用并返回 410；原版调试接口已移除。公开的旧默认管理员邀请码会撤销，撤销邀请码不会删除用户。

旧版 Google 账号可能缺少稳定 subject 绑定；禁止按邮箱自动合并，以免未验证的邮箱注册抢占账号。部署到旧库前，管理员必须独立核实原账号归属和 Google 返回的 `sub`，再使用 `scripts/link_google_identity.py` 恢复。默认只预览，显式提供 `--apply --ownership-verified` 才写入，且拒绝将已有身份改派。**本次没有运行该工具修改现有用户库**。不要仅依据用户提交的邮箱或未经验证的 token 进行绑定。
