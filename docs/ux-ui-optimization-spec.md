# Video Gaga UX/UI 优化 Spec 方案

## 一、当前设计现状分析

### 1.1 信息架构

| 层级 | 页面/模块 | 核心功能 |
|------|----------|----------|
| L1 首页 | `/` | 品牌展示 + 快速入口 |
| L1 灵感 | `/inspiration` | 瀑布流灵感展示 |
| L1 项目 | `/projects` | 项目管理 + 资产库 |
| L2 工作流 | `/workflows` | 模式选择（小白/专业）|
| L3 步骤 | `/workflows/pro/step-{1-7}` | 分步创作流程 |

### 1.2 现有交互模式

- **导航**: 顶部固定导航栏（灵感广场、我的项目）
- **工作流**: 左侧步骤进度条 + 中央内容区 + 底部操作栏
- **主题**: 支持 Light/Dark 双主题，首页固定 Dark 主题

## 二、核心问题诊断

### 2.1 信息层级问题

```
问题: 工作流步骤过多（7步），用户容易迷失
当前: 故事设定 → 参数设定 → 场景/角色/道具 → 分镜脚本 → 视频预览
建议: 合并为 4 个里程碑阶段，减少认知负担
```

### 2.2 交互一致性问题

| 问题 | 位置 | 影响 |
|------|------|------|
| 返回按钮样式不统一 | `WorkflowTopBar` vs `WorkflowStepNav` | 用户困惑 |
| 保存/提交操作位置不一致 | 有的在右下角，有的在底部中央 | 操作路径不稳定 |
| AI 生成按钮视觉权重混乱 | 有时主按钮，有时次级按钮 | 优先级不清晰 |

### 2.3 视觉反馈缺失

- **加载状态**: 仅有文字"生成中..."，无进度指示
- **成功反馈**: 操作完成后无明确成功提示
- **错误处理**: 错误信息样式不统一，位置分散

## 三、优化方案 Spec

### 3.1 导航架构重构

```
建议的导航结构:

┌─────────────────────────────────────────┐
│  Logo    [灵感广场] [我的项目]    🌙 👤  │  ← 简化顶部导航
├─────────────────────────────────────────┤
│  ┌────────┐  ┌──────────────────────┐  │
│  │        │  │                      │  │
│  │ 步骤   │  │    主内容区域         │  │
│  │ 进度   │  │                      │  │
│  │ 侧边栏  │  │                      │  │
│  │        │  │                      │  │
│  └────────┘  └──────────────────────┘  │
│              [上一步]        [下一步]   │  ← 固定底部操作栏
└─────────────────────────────────────────┘
```

**具体改动:**

1. **顶部导航简化**
   - 移除工作流页面内的冗余返回按钮
   - 统一使用面包屑导航替代多级返回

2. **步骤进度优化**
   - 当前: 5 个文字步骤
   - 建议: 4 个图标 + 文字里程碑
     - 📝 构思（故事设定）
     - ⚙️ 配置（参数 + 风格）
     - 🎨 资产（场景/角色/道具）
     - 🎬 成片（分镜 + 视频）

### 3.2 工作流步骤合并

**Step 1: 故事构思** (合并原 step-1 + story-setting)
```
┌────────────────────────────────────────┐
│  [AI 辅助] [自己写]                     │  ← 模式切换 Tab
├────────────────────────────────────────┤
│  ┌──────────────┐  ┌────────────────┐ │
│  │ AI 对话区     │  │ 故事草稿编辑区  │ │
│  │              │  │                │ │
│  │ 实时扩写建议  │  │ [提交故事设定]  │ │
│  └──────────────┘  └────────────────┘ │
└────────────────────────────────────────┘
```

**Step 2: 视觉配置** (合并参数 + 风格)
```
┌────────────────────────────────────────┐
│  画面比例  [16:9 ▼]                    │
│                                        │
│  创作模式  [图生视频 ▼]                 │
│  分镜模式  [自动生成 ▼]                 │
│                                        │
│  风格选择  [2D动漫] [3D写实] [像素] ...  │
│  ┌────┐ ┌────┐ ┌────┐                 │
│  │预览│ │预览│ │预览│                 │
│  └────┘ └────┘ └────┘                 │
│                                        │
│           [开始生成资产]                │
└────────────────────────────────────────┘
```

**Step 3: 资产管理**
```
优化点:
1. 场景/角色/道具 改为横向 Tab，而非切换页面
2. 每个卡片统一布局: 预览图 + 名称 + 操作
3. 批量操作工具栏: [全选] [批量生成] [批量删除]
```

**Step 4: 分镜与成片**
```
优化点:
1. 分镜列表支持拖拽排序（已实现，需增加视觉反馈）
2. 分镜卡片增加缩略图预览区域
3. 台词与音色设置折叠，默认收起
4. 增加"生成视频"主按钮在右上角
```

### 3.3 设计系统统一

**按钮层级规范:**

| 类型 | 使用场景 | 样式 |
|------|----------|------|
| Primary | 主操作（提交、生成、保存） | 品牌色填充 |
| Secondary | 次要操作（返回、取消） | 描边样式 |
| Tertiary | 辅助操作（编辑、删除） | 文字按钮 |
| Danger | 破坏性操作（删除确认） | 红色提示 |

**状态反馈规范:**

```tsx
// 建议添加的组件
<LoadingState
  type="progress" // spinner | progress | skeleton
  message="正在生成场景..."
  progress={45}   // 可选
/>

<EmptyState
  icon="scene"
  title="还没有场景"
  description="完成故事设定后，AI 会自动生成场景"
  action={{ label: "去设定故事", href: "/step-1" }}
/>

<Toast
  type="success | error | info"
  message="保存成功"
  duration={3000}
/>
```

### 3.4 响应式布局优化

**当前问题:** 工作流在小屏幕下左侧进度条占用过多空间

**解决方案:**

```css
/* 断点策略 */
< 768px:   进度条变为顶部横向步骤条
768-1024px: 进度栏折叠为图标模式
> 1024px:   完整侧边栏
```

### 3.5 微交互优化清单

| 位置 | 当前 | 优化建议 |
|------|------|----------|
| 项目卡片 | 静态 | hover 时显示快捷操作（编辑、删除、继续）|
| 资产卡片 | 点击编辑 | 悬停预览大图，点击展开详情抽屉 |
| 分镜拖拽 | 基础实现 | 增加拖拽占位符、释放区域高亮 |
| 生成按钮 | 文字变化 | 增加脉冲动画 + 进度环 |
| 输入框 | 基础样式 | focus 时增加品牌色光晕 |

## 四、优先级与实施建议

### Phase 1: 快速优化（1-2 周）
- [ ] 统一按钮样式与位置
- [ ] 添加加载状态组件
- [ ] 优化空状态展示

### Phase 2: 结构优化（2-3 周）
- [ ] 工作流步骤合并
- [ ] 响应式布局重构
- [ ] 导航架构简化

### Phase 3: 体验提升（3-4 周）
- [ ] 微交互动画
- [ ] 键盘快捷键支持
- [ ] 操作引导/Onboarding

---

## 五、关键指标建议

1. **任务完成率**: 从创建项目到生成视频的转化率
2. **步骤流失率**: 每个步骤的跳出率分析
3. **操作效率**: 完成各步骤的平均时间
4. **错误率**: 表单验证失败、API 错误的频率
