# 用户登录 & 注册

## 基本信息

| 字段 | 内容 |
| --- | --- |
| 模块 | 登录弹窗（全局） |
| 负责人 | 前端 |
| 版本 | v0.1 |
| 更新日期 | 2026-02-05 |

## 目标
- 为未登录用户提供统一登录入口。
- 全局可触发，任何页面无需重复引入。

## 现状
- 登录弹窗在 Provider 内统一渲染。
- 支持账号密码登录（注册待扩展）。
- 登录成功会更新用户名与登录态。

## 交互
- 打开：触发登录动作时展示弹窗。
- 关闭：点击关闭或登录成功后自动关闭。

## 视觉
- 左侧视频背景 + 右侧玻璃拟态卡片。

## 边界与风险
- 视频背景加载性能与缓存策略。
- 未来需增加注册/第三方登录时的流程调整。

## 待办
- 注册流程设计
- 错误提示与表单校验
