# 前端页面布局规划 PRD

## 1. 目标
- 统一首页/登录/灵感广场的布局规范，确保视觉一致与可扩展。
- 明确页面层级与布局区域，降低后续迭代成本。
- 保证不同屏幕尺寸下的可用性与沉浸式体验。

## 2. 范围
- 首页（Home）
- 登录弹窗（全局）
- 灵感广场（Inspiration）
- 全局布局（侧边栏 + 头像菜单）

## 3. 页面布局规划

### 3.1 全局布局（AppShell）
- 左侧：固定侧边栏（常驻）。
- 右上：头像/登录入口（常驻）。
- 内容区：页面主体，留出侧边栏宽度。
- 交互：头像菜单点击打开，点击外部或空闲 5 秒关闭。

### 3.2 首页（Home）
- 背景层：全屏视频背景。
- 内容层：标题 + 搜索/输入框 + 电影胶片。
- 布局关系：
  - 标题居中上部，输入框位于标题下方（用于项目/剧本名）。
  - 电影胶片位于输入框下方，占据主要视觉区域。
  - “探索更多灵感”入口位于胶片上方居中。
- 交互状态：
  - 输入框用于项目/剧本命名，回车或点击按钮创建新项目。

### 3.3 登录弹窗（全局）
- 容器：居中弹窗，覆盖全屏遮罩。
- 布局：左侧视频背景 + 右侧表单区域。
- 交互：打开/关闭、登录成功后更新状态。

### 3.4 灵感广场（Inspiration）
- 顶部区域：左上返回按钮，右上头像/登录。
- 内容区：瀑布流/卡片流，自适应屏幕宽度。
- 侧边栏：保持可见并高亮灵感入口。

## 4. 响应式与适配
- 保证输入框、胶片与瀑布流在不同宽度下不溢出。
- 关键区域保持居中/视觉焦点不偏移。

## 5. 风险与待优化
- 视频背景加载性能与缓存策略。
- 聚焦遮罩与点击区域冲突。
- 不同分辨率下的布局密度。

## 6. 验收标准（前端）
- 不同分辨率下主内容不溢出、不遮挡侧边栏。
- 聚焦输入框后遮罩完整，交互不误触。
- 页面结构与交互一致性符合上述规划。
